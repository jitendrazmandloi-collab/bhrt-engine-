# BHRT Engine — Streamlit Deployment Guide

## Step 1: GitHub Repo Update

1. Tere existing `bhrt-engine` repo mein jao
2. `app.py` aur `requirements.txt` (streamlit wala) upload karo
3. Commit changes

## Step 2: Streamlit Cloud Sign Up

1. Browser mein jao: **share.streamlit.io**
2. **Sign up with GitHub** — same account jo repo pe hai
3. Authorize karo

## Step 3: Deploy

1. Dashboard pe **"New app"** button click karo
2. Repository select karo: `jitendrazmandloi-collab/bhrt-engine`
3. Main file path: `app.py`
4. **Deploy** button click karo
5. 2-3 minute wait karo

## Step 4: Link mil jayegi

Example: `https://jitendra-bhrt.streamlit.app`

Ye link kisi ko bhi bhej sakte ho — phone, laptop, kahi se bhi chalega.

## Step 5: Custom Domain (Optional)

1. Streamlit dashboard mein app ke settings
2. **"Custom domain"** section
3. Apna domain daalo (e.g., `bhrt.mandloi.com`)
